Лабораторная работа 4. Базовые растровые алгоритмы

Наведите курсор на сетку.

Привязка к сетке: целочисленная координата (x, y) — это центр клетки; клетка занимает [x−0.5; x+0.5]×[y−0.5; y+0.5]. Оси проходят через центры клеток нуля, ось y направлена вверх. Серые точки — центры клеток, т.е. узлы с целыми координатами.

Сопроводительные вычисления (пример)

Все замеры идут только по виртуальному растру (Float32Array 1201×1201), без UI, таймер — performance.now(). «Солнце»: отрезки из центра под случайным углом, значит, попадают во все 8 октантов. Для каждого алгоритма берётся лучший из нескольких прогонов, перед замерами — прогрев.
